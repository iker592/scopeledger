# ScopeLedger

**Keep the project. Charge for the extra work.**

A launch preview for independent Webflow and WordPress designers who need to price requests beyond an agreed project brief.

[Open the free workspace](https://scopeledger.starryharp64.chatgpt.site)

- Record agreed deliverables and hourly rate.
- Turn an extra request into an itemized estimate with an optional contingency buffer.
- Print a change-order draft or save it as a PDF.
- Track sent, approved, or declined decisions manually.
- Export and import project backups.

Project data stays in your browser. There is no cloud synchronization, email sending, electronic signature, payment collection, or proof of client approval. Get written client agreement through your own process before starting additional work.

## Feedback

[Report a problem or request a feature](https://github.com/iker592/scopeledger/issues/new/choose). Please use fictional examples; do not post client names, messages, contracts, payment details, or other private information in public issues.

## Commercial status

The current preview is free. Paid offers and pricing are being explored; there is no live checkout or subscription. This repository contains public resources and a feedback channel, not private company records.
